เพิ่มระบบคำขอลบ WORK LOG

1. ผู้กรอก
- ในประวัติ WORK LOG จะมีปุ่ม “ขอให้ Admin ลบรายการ”
- ผู้กรอกต้องระบุเหตุผลก่อนส่งคำขอ
- ระบบสร้างแท็บ DELETION REQUESTS อัตโนมัติ
- WORK LOG จะยังไม่ถูกลบทันที
- หากส่งคำขอซ้ำรายการเดิม ระบบจะแจ้งว่ามีคำขอรออนุมัติแล้ว

2. ADMIN
- โซน Admin แสดงจำนวนคำขอลบที่รออนุมัติ
- แสดง Request ID, Work ID, ผู้ขอลบ, เหตุผล และเวลาที่ขอ
- มีปุ่ม “อนุมัติและลบรายการ”
- เมื่อ Admin อนุมัติ ระบบจะลบ WORK LOG ออกจากประวัติจริง
- ระบบย้อนรายการ INVENTORY ที่เกี่ยวข้องให้เหมือนการลบเดิม
- เก็บสำเนาไว้ใน DELETED WORK LOG เพื่อเป็นหลักฐานย้อนหลัง
- คำขอจะเปลี่ยนสถานะเป็น APPROVED

3. Google Apps Script
- ใช้ Spreadsheet ID เดิม
- ใช้ Drive Folder ID เดิมสำหรับรูป WORK LOG
- ต้อง Deploy Web App เวอร์ชันใหม่หลังนำ Code.gs นี้ไปวาง
- ใช้ Execute as Me และ Anyone ตามการตั้งค่าที่ใช้งานอยู่
