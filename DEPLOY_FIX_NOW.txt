MYSTICAL BEASTS ALLIANCE — WORK LOG FIX

สาเหตุที่แก้ในรุ่นนี้
- หน้าเว็บเดิมใช้ fetch POST แบบ no-cors จึงไม่สามารถอ่านผลลัพธ์จาก Apps Script ได้ และอาจขึ้นว่า "บันทึกแล้ว" แม้ Apps Script จะตอบ error
- รูปการทำงานเดิมไม่ถูกบังคับที่หน้าเว็บ แม้ฝั่ง Apps Script จะบังคับให้มีรูป
- ระบบใหม่สร้าง Request ID และบันทึกผลลงแท็บ API STATUS เพื่อให้หน้าเว็บตรวจผลจริงผ่าน JSONP

สิ่งที่แก้แล้ว
1. WORK LOG ต้องแนบรูปก่อนบันทึก
2. รูปถูกย่อเป็น JPEG ก่อนส่ง เพื่อลดขนาด payload
3. POST ไป Apps Script ใช้ Request ID
4. Apps Script สร้าง/ใช้แท็บ API STATUS
5. หน้าเว็บรอผลจริงจาก API STATUS
6. ถ้า Apps Script บันทึกไม่สำเร็จ หน้าเว็บจะแสดง Error จริง
7. ADMIN ลบ WORK LOG ใช้กลไกตรวจผลเดียวกัน
8. ใช้ WORK LOG Web App URL เดียวกับ ADMIN
